# Ясно

Демонстрационная платформа по киберграмотности. Только HTML, CSS и JavaScript: ничего устанавливать не нужно.

Автор сценария — вымышленный персонаж Иванко Сергей Романович. Оплаты, аккаунтов и отправки писем нет.

## Как открыть

1. Распакуйте папку.
2. Откройте файл `index.html` двойным щелчком.

Если браузер блокирует скрипты с диска, залейте папку как есть на любой статический хостинг (GitHub Pages, Netlify Drop) — файлы уже лежат в корне, сборка не нужна.

## Что работает

- Главная, каталог с поиском, фильтрами и сортировкой
- Страница курса, отметки уроков в этом браузере
- Демонстрационная «запись» без платежа
- Тест с пояснениями и рекомендацией
- Материалы, автор, FAQ
- Контактная форма с проверкой полей (письмо никуда не уходит)
- Светлая и тёмная тема, запоминается в браузере

## Публикация на GitHub Pages

1. Создайте репозиторий на сайте GitHub. В поле .gitignore оставьте **No .gitignore**.
2. Нажмите **uploading an existing file** и перетащите содержимое этой папки (`index.html`, `styles.css`, `app.js`, `data.js`, `favicon.svg`).
3. В настройках репозитория откройте **Pages** и выберите ветку `main` и папку `/root`.

Через минуту сайт откроется по адресу `https://ВАШ-НИК.github.io/ИМЯ-РЕПО/`.
